Como usar

1. Baixe o modelo CSV e preencha com seus dados autorizados.

2. Importe os clientes. Use o mesmo ID para agrupar as compras da mesma pessoa.

3. Filtre por loja, bairro e clientes sem recompra.

4. Abra o WhatsApp direto pelo card para fazer pós-venda ou reativação.

Protótipo local: os dados ficam neste navegador. Não publique base real de clientes no GitHub.

Esta é uma demonstração estática e local, sem autenticação ou banco de dados compartilhado. Para operação real com várias lojas: login, permissões, armazenamento seguro, registro de consentimento/base legal e controle de acesso conforme a LGPD são indispensáveis.
