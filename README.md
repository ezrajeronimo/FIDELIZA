# FIDELIZA 7.2 — Design Premium

Reestilização do FIDELIZA 7.1 com referência de ritmo visual e transições do site Poytara, preservando a identidade UNIGAMES, filtros de crediário e integração com Supabase.

## Instalação
Substitua apenas `index.html` no GitHub. **Mantenha o `config.js` existente.** Não altere SQL.

## Melhorias
- Paleta azul-marinho + azul petróleo + verde-água de acento; superfícies claras
- Menu lateral em gradiente e indicação de seleção
- Animações discretas em páginas, barras e botões
- Pódio minimalista
- Contrastes de foco e respeito a `prefers-reduced-motion`

Esta revisão não modifica as tabelas nem o código de importação. Teste no navegador antes do uso produtivo.
